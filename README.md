# SeriousPortal — портальная пушка Portal в Serious Sam Classic

Порт Portal на основе [SeriousBridge](https://github.com/animeliodas/SeriousBridge) (ядро для переноса механик других
игр в Serious Sam Classic). Portal не запускается: её правила переписаны внутри плагина Sam, а из самой Portal с
установки игрока берутся только звуки. Соседние порты: [SemCraft 2](https://github.com/animeliodas/SemCraft2) (Minecraft),
[SeriousHL](https://github.com/animeliodas/SeriousHL) (движение Half-Life; вместе с ним скорость через порталы сохраняется).

> Сделано с помощью Claude Code (ИИ). Проверено в TFE 1.05 (Аллея сфинксов): `tools/test_portal.py` 3/3, в том
> числе на ядре SeriousBridge и вместе с SeriousHL (2026-10-13).

## Как играть

| Клавиша | Что делает |
|---|---|
| **Z** | синий портал туда, куда смотрит прицел |
| **X** | оранжевый портал |
| **C** | закрыть оба |

- Портал встаёт на стену, пол или потолок (брашевую поверхность); на дверь, лифт, в небо или поверх второго — нет
  (звук «нельзя»). На стене он садится на пол под собой и не заходит под потолок, а по поверхности сдвигается (до
  метра), пока весь овал не ляжет на неё — как в Portal.
- Что входит в один, выходит из другого: игрок, монстры, ракеты, гранаты, ядра, предметы. Скорость и направление
  поворачиваются вместе с ними: упав с высоты в портал на полу, вылетаешь из стены с той же скоростью.
- Портал на полу забирает того, кто на нём стоит (в Portal под ногами — пол открыт).
- Сквозь портал видно, что за другим (настоящая картинка мира с той стороны).
- Клавиши меняются в консоли: `sp_iKeyBlue`, `sp_iKeyOrange`, `sp_iKeyClose` (коды клавиш Windows);
  `sp_iSeeThrough = 0` — без картинки сквозь порталы (дешевле).

## Установка

1. Serious Sam Classic с [Classics Patch 1.9.4](https://github.com/SamClassicPatch/SuperProject/releases/tag/1.9.4).
2. Собрать плагин: `plugin/build.sh` (VS 2022 Build Tools v143). Рядом с этим репозиторием нужны
   [SeriousBridge](https://github.com/animeliodas/SeriousBridge) (папка `seriousbridge`, или `$SERIOUSBRIDGE`) и SDK
   Classics Patch 1.9.4 (`_deps/SuperProject`, или `$SUPERPROJECT`):
   ```
   <папка>/seriousportal      этот репозиторий
   <папка>/seriousbridge      git clone https://github.com/animeliodas/SeriousBridge seriousbridge
   <папка>/_deps/SuperProject git clone --branch 1.9.4 --recurse-submodules https://github.com/SamClassicPatch/SuperProject.git
   ```
3. `uv run --with vpk python tools/install_portal.py --tfe "<папка TFE>" --tse "<папка TSE>"` — кладёт DLL в
   `Bin\Plugins`, а звуки портальной пушки достаёт из **вашей** Portal (Steam, `portal_pak_dir.vpk`) и через ffmpeg
   переводит в PCM WAV в `Sounds\SeriousPortal` игры. Звуки Valve в репозиторий не входят. Без Portal или ffmpeg
   порталы работают беззвучно. Удалить: `--uninstall`.

## Как устроено

Ядро SeriousBridge даёт плагину аллокатор движка, игрока (`player::Local`), физику (`physics::PlaceNow` — телепорт со
скоростью) и dev-хук. Своё у порта:

- **Порталы** (`Portals.cpp`): луч от глаз по брашам (`CCastRay`, модели не держат портал), нормаль полигона —
  наружу. Базис овала: N (наружу), U (на стене — мировой верх, на полу — от стрелявшего), R = U × N. Переход:
  каждый тик для подвижных сущностей (игрок, `Enemy Base`, `Projectile`, `Item`) — зазор между их коробкой и
  плоскостью портала, проекция центра в овал; «вошёл», если зазор < 0.15 м и движется внутрь (или стоит на портале на
  полу). Выход: та же точка по ту сторону (R и N разворачиваются, U остаётся), коробка на 0.3 м от поверхности,
  скорость тем же поворотом; игроку меняется только курс, монстрам и снарядам — весь поворот. Стена за порталом
  остаётся твёрдой — мир Sam не меняется.
- **Картинка сквозь портал** (`View.cpp`, `Gl.cpp`): перед кадром Sam (`OnPreDraw`) мир рисуется движком ещё раз —
  из точки, куда попала бы камера, пройдя портал, с **warp-плоскостью** проекции (`CProjection3D::WarpPlaneL`, тот
  же механизм, что у варп-порталов движка) по поверхности второго портала — в четверть кадра, и копируется в
  текстуру. После мира (`OnRenderView`) овал рисуется с этой текстурой проективно (координаты — экранная позиция
  вершины), с depth-test против глубины Sam (диапазон 0..0.9, `glFrustum` как у движка).
- **Звуки** (`Sounds.cpp`): `CSoundObject::Play_t` из `Sounds\SeriousPortal\*.wav`.

## Проверка

`tools/test_portal.py --game "<папка игры>"` (игра запущена с `SERIOUSBRIDGE_DEV=1`, команды через
`%TEMP%\SeriousPortal\cmd.txt`), TFE 1.05, Аллея сфинксов, 3/3:
1. синий портал на полу, оранжевый — на стене башни (найден перебором направлений), картинки сквозь них рисуются;
2. с 12 м в синий — вылет из стены: 10.2 м/с, вбок, в 4 м от оранжевого;
3. C закрывает оба.

Глазами (скриншоты): овалы с кольцами, сквозь оранжевый на стене — вечернее небо над синим порталом на полу.

## Грабли

1. Движковые заголовки и `<GL/gl.h>` в одном файле конфликтуют (`GLenum`) → весь OpenGL — в `Gl.cpp` без
   заголовков движка, интерфейс на массивах.
2. `Engine/Rendering/Render.h` вместе с `Core.h` даёт переопределение `CWorldRenderPrefs` — `RenderView` и так
   объявлен.
3. Лицевая сторона стен в уровнях бывает «полупрозрачным порталом» поверх твёрдой стены: с
   `cr_bHitTranslucentPortals = FALSE` луч проходит её, портал встаёт на стену позади и прячется по глубине.
4. Warp-плоскость: нормаль — **внутрь** поверхности второго портала (`-N`), точка — на 5 см перед ней (иначе сама
   поверхность остаётся в кадре: камера за полом видит пол снизу).
5. WAV для движка: только PCM и `data` сразу после `fmt` — у ffmpeg по умолчанию между ними `LIST` (метаданные):
   `-map_metadata -1 -fflags +bitexact -flags:a +bitexact`.
6. `OnFrame` у плагинов принимает `CDrawPort *`, `OnStep` — без аргументов.
7. Портал на полу под ногами забирает игрока сразу (так в Portal) — тест ставит его в паре метров.
8. Картинки сквозь порталы рисуются в четверть экрана: другой плагин (SemCraft 2) пропускает такие виды по размеру и
   не путает их со своим главным видом.
